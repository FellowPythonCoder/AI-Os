# Customization

Open **AURA Settings** for the visual theme editor with live previews,
or use `aura` commands in Celestia Shell. Everything is saved instantly
and survives reboots.

## Appearance

- Light / Dark mode, seven accent colors (or any custom hex)
- Wallpapers: four built-in mountain scenes, or any image in ~/Pictures
- Icon theme, cursor theme, fonts and UI text size
- Transparency, shadows and animation toggles (Settings → Effects)

## Dock & menu bar

- Dock size, position (bottom/left/right/top), magnification, auto-hide
- Panel icon size and which indicators appear (Settings → Menu Bar)

## Terminal

Celestia Shell colors, fonts and opacity live in Settings → Terminal.
Shell-level tweaks go in `~/.zshrc` (interpreted after the system
defaults in `/etc/celestia/zshrc`).

## Reset

Changed too much? Settings → Appearance → **Restore AURA Defaults**, or
run `aura theme reset`. Your files are never touched.
