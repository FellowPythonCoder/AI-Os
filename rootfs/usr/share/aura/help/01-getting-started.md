# Getting Started

Welcome to **AURA OS** — a blue-mountain desktop built on Debian GNU/Linux,
running as a virtual machine on your Mac through UTM.

## The layout

- **Top menu bar** — the AURA menu (click 🏔 AURA), the current app's menu,
  status icons, volume, power, clipboard history and the clock.
- **Dock** (bottom center) — your favorite and running apps. Icons grow as
  your pointer approaches; a dot beneath an icon means the app is running.
  Right-click an icon to pin/unpin or quit. Drag icons to rearrange them.
- **Desktop** — files and folders live here; right-click for options.
- **Search** — press **Super + Space** to find apps and commands instantly.

## First things to try

1. Open **Celestia Shell** from the dock and run `aura help`.
2. Personalize colors in **AURA Settings → Appearance**.
3. Browse **AURA App Center** for thousands of free applications.
4. Run `aura doctor` in Celestia Shell to verify everything is healthy.

## Your files

Your home folder holds Desktop, Documents, Downloads, Music, Pictures,
Videos, plus **Notes** and **Projects**. If you shared a Mac folder in UTM,
it appears in AURA Finder under Network / shared mounts — see *UTM Tips*.
