# Keyboard Shortcuts

## System

- **Super + Space** — Spotlight-style search (apps & commands)
- **Super + Enter** or **Ctrl + Alt + T** — Celestia Shell
- **Super + E** — AURA Finder
- **Super + B** — AURA Browser
- **Super + ,** — AURA Settings
- **Super + L** — Lock screen
- **Super + V** — Clipboard history
- **Ctrl + Shift + Esc** — Task Manager

## Windows & workspaces

- **Super + ← / →** — Tile window to half the screen
- **Super + ↑ / ↓** — Maximize / minimize
- **Super + F** — Fullscreen · **Super + W** — Close window
- **Super + Tab** — Switch windows
- **Super + D** — Show desktop
- **Ctrl + Alt + ← / →** — Switch workspace

## Screenshots

- **Print** — Full screen · **Shift + Print** — Region · **Alt + Print** — Window

## In Celestia Shell

- **Ctrl + R** — Search command history
- **Ctrl + Shift + T / W** — New / close tab
- **Ctrl + Shift + C / V** — Copy / paste
- **↑** after typing — find matching history

Shortcuts can be changed in Settings → Keyboard.
