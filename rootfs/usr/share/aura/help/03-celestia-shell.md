# Celestia Shell

Celestia Shell is AURA's terminal: a real Zsh environment with syntax
highlighting, autosuggestions, searchable history and the friendly
`aura` command built in.

## Essential aura commands

- `aura help` — the full command guide
- `aura fetch` — logo + system summary
- `aura system` — detailed info, including RAM given to this VM
- `aura apps` — list installed apps · `aura open notes` opens one
- `aura theme dark` / `aura theme accent glacier` — appearance
- `aura wallpaper set aura-aurora-ridge` — change wallpaper
- `aura search blender`, `aura install blender` — software
- `aura update`, `aura upgrade` — system updates
- `aura clean` — safe cleanup (previews first)
- `aura doctor` — health check with plain-English fixes
- `aura session lock` — lock the screen

## Everyday Linux commands

Everything standard works: `ls`, `cd`, `mkdir`, `cp`, `mv`, `rm`,
`cat`, `grep`, `find`, `ssh`, `curl`, `wget`, `git`, `python3`, `node`.
Use `man <command>` for any manual, and `--dry-run` with aura commands
to preview changes safely.

## Productivity features

- **Tab** completes commands and filenames; tab again for a menu.
- **↑ / ↓** search history matching what you've typed.
- **Ctrl + R** searches your whole history.
- Type `aura tutorial` any time for the interactive tour.
- Split panes: right-click in the terminal, or use tabs with Ctrl+Shift+T.
