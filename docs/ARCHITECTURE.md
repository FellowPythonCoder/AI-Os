# AURA OS — Architecture

AURA is a **Debian 12 (bookworm) ARM64 derivative** with a heavily customized
Xfce desktop. It deliberately reuses battle-tested Linux components for
everything hard (kernel, drivers, package management, session, updates) and
adds a thin, well-defined AURA layer on top: branding, themes, the `aura`
CLI, Celestia Shell, six small GTK apps, and curated defaults.

```
┌──────────────────────────────────────────────────────────────────┐
│  AURA apps (Python/GTK): Settings · App Center · Welcome ·      │
│  Notes · Monitor · Help · About          Celestia Shell (zsh)    │
├──────────────────────────────────────────────────────────────────┤
│  aura CLI  ── single source of truth for theme/wallpaper/dock/  │
│  packages/session. GUIs and shell both call it, so they can      │
│  never disagree. Config: ~/.config/aura/config.json              │
├──────────────────────────────────────────────────────────────────┤
│  Desktop: Xfce 4.18 (panel+appmenu, xfwm4, xfdesktop, Thunar) ·  │
│  Plank dock · LightDM+slick-greeter · xfce4-notifyd · PipeWire   │
├──────────────────────────────────────────────────────────────────┤
│  AURA themes: AuraDark/AuraLight (GTK3+GTK4+xfwm4, generated    │
│  from design tokens) · AuraIcons · AuraCursor · sound theme ·    │
│  Plymouth + GRUB themes · 4 wallpapers                           │
├──────────────────────────────────────────────────────────────────┤
│  Debian 12 ARM64 · systemd · APT/dpkg · Flatpak/Flathub ·        │
│  Linux kernel (Debian) · QEMU/UTM guest tools (SPICE)            │
└──────────────────────────────────────────────────────────────────┘
        UTM (Apple Virtualization backend) on Apple Silicon
```

## Repository layout

| Path | What lives there |
|---|---|
| `rootfs/` | The AURA overlay — a mirror of `/`. Everything that makes Debian into AURA: `/usr/bin/aura*` programs, themes, icons, wallpapers, desktop entries, `/etc/skel` defaults, Celestia config, Plymouth/GRUB/LightDM branding. |
| `build/packages/` | The single source of truth for package sets (`core`, `optional`, `live`, `image`). |
| `build/build-iso.sh` | live-build → bootable live/installer ISO (Calamares). |
| `build/build-image.sh` + `build/debos/` | debos → preinstalled UTM disk image (.img/.qcow2). Recipe generated by `tools/render_debos_recipe.py`. |
| `installer/install-aura.sh` | Transforms a running Debian 12 into AURA (with `--dry-run` and backups). |
| `rootfs/usr/share/aura/finalize.sh` | Shared post-overlay finalization (schemas, icon caches, Plymouth/GRUB, LightDM, Flathub, user prep) used by **all three** install paths. |
| `tools/` | Asset generators (icons, cursors, themes, xfwm4 XPMs, sounds, desktop files, debos recipe). Generated files are committed; CI fails if they drift. |
| `tests/` | 17 tests: CLI behavior (real subprocess runs against temp configs), asset/XML/JSON validity, generator reproducibility. |
| `.github/workflows/` | CI (tests, shellcheck, desktop-file-validate) + ARM64 image/ISO builds. |

## Key design decisions

**One CLI to rule the settings.** Appearance state lives in
`~/.config/aura/config.json`. The `aura` CLI applies it (xfconf-query,
gsettings, a per-user `AuraCustom` GTK theme whose `accent.css` is
rewritten). AURA Settings and Welcome are GTK front-ends over the same CLI —
change the accent in Celestia and the Settings app shows it too.

**Themes are generated, not hand-edited.** `tools/generate_themes.py` holds
two palettes and emits GTK3/GTK4 CSS; `tools/generate_xfwm4.py` rasterizes
XPM window decorations pixel-by-pixel; `generate_cursors.py` writes real
binary XCursor files (including an 8-frame animated spinner);
`generate_sounds.py` synthesizes the whole sound theme from sine waves.
This keeps 60+ asset files consistent and reviewable.

**Real apps behind AURA names.** Each `AURA X` launcher is a `.desktop`
file whose `Exec` is a real program (Thunar, Firefox ESR, Geany, Timeshift…),
with an AURA icon and name; the original entries are hidden per-user so menus
show exactly one clean set. Six apps are written for AURA (Settings,
App Center, Welcome, Notes, Monitor, Help, About) in dependency-light
Python 3 + GTK 3.

**Maintainable base.** No patched system libraries, no fragile forks:
`sudo apt upgrade` (or `aura upgrade`) keeps the OS current exactly like
Debian. The overlay can be re-applied at any time; replaced files are backed
up by the installer.

## Boot chain (UTM, UEFI)

UTM's UEFI firmware → GRUB (AURA theme) → Debian ARM64 kernel + initramfs
(Plymouth "aura" splash) → systemd → LightDM (slick-greeter, AURA skin) →
Xfce session (panel, Plank, xfdesktop) → first-run Welcome wizard.
